      • 0001 — v3 is a binary module on net8.0 for PowerShell 7.4+
      • 0002 — Which sinks and enrichers v3 keeps
      • 0003 — v3 keeps the v2 extension contract
      • 0004 — Refreshed extensions require PoShLog 3
      • 0005 — Destructure PowerShell objects as PowerShell users see them
      • 0006 — Push-LogContextProperty scopes with a script block or a bookmark
      • 0007 — Core writes CLEF with its own formatter
      • 0008 — The PowerShell sink shows Error and Fatal like Write-Host
      • 0009 — First-party sinks; other authors' sinks are a non-blocking check
      • 0010 — v2 stays a maintained line for Windows PowerShell 5.1
      • 0011 — Core does not load assemblies that published extensions ship
      • 0012 — The OpenTelemetry sink: a compiled cmdlet, OTLP/HTTP by default, parameters before environment
      • 0013 — The Splunk HEC sink: compiled cmdlet, own batching, migration aliases
      • 0014 — The Syslog sink: the package's formatters, our own transports
      • 0015 — The Elastic sink: data streams over the bulk API, dropping when the buffer is full
      • 0016 — Convert-LogFunctions is a conservative, reviewable helper
      • 0017 — Extensions require PoShLog 2.99.0 while Core 3 is a prerelease
      • 0018 — Release modules by pushing a tag
      • 0019 — Extensions ship as prereleases during the Core 3 preview
      • 0020 — Integration tests against real backends
      • 0021 — Core lists and installs its extensions from a catalogue built into the assembly
      • 0022 — The documentation website: Starlight built from docs/, served at poshlog.github.io from an org site repository
      • 0023 — Safe error invocation metadata and explicit Event Log source management
      • 0026 — Resolve file sink paths through the PowerShell provider
      • 0027 — Filter sublogger routing with Serilog expressions
      • 0028 — Load a Serilog JSON configuration snapshot
      • 0029 — Build custom Serilog console token themes
      • 0030 — MSSqlServer isolates dependencies and shares Serilog with Core
      • 0032 — Shade Serilog.Expressions into Core
      • 0033 — v3 targets net10.0 and PowerShell 7.6+

Write-WarningLog

Writes a Warning log message.

Description

Section titled “Description”

Write a log event with the Warning level.

Implemented as the compiled WriteWarningLogCommand cmdlet class (src/dotnet/Cmdlets/Write/WriteWarningLogCommand.cs), sharing the common WriteLogCmdletBase.
